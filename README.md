# 📊 LeetCode Status Tracker

## 📌 Overview

**LeetCode Status Tracker** is a comprehensive web application developed for academic institutions and placement cells to monitor, analyze, and compare students' coding progress on LeetCode.

Built using **React JS**, **Node JS**, **Express JS**, **MongoDB**, and **Chart JS**, the system enables staff members to track student performance, generate rankings, monitor improvements, and automatically create periodic reports for placement preparation activities.

## 🎯 Features

- 👨‍🎓 **Student Progress Tracking:** Monitor Easy, Medium, and Hard problem counts

- 📈 **Performance Comparison:** Compare previous and current coding statistics

- 🏆 **Student Rankings:** View rankings based on LeetCode performance

- 📚 **Batch & Section Management:** Filter and analyze students by batch and section

- 📊 **Interactive Analytics Dashboard:** Visualize progress using charts and graphs

- 📄 **Automated Monthly Reports:** Generate reports at predefined intervals

- 📧 **Automatic Report Distribution:** Email consolidated reports to the Placement Coordinator

- 🔐 **Staff Authentication:** Secure access for authorized faculty members

- 📋 **Improvement Tracking:** Store and display coding growth over time

- 📉 **Department-Wide Insights:** Analyze coding activity across multiple sections

## 📈 Report Generation Schedule

The system automatically generates coding progress reports on:

- 📅 4th of Every Month

- 📅 11th of Every Month

- 📅 18th of Every Month

- 📅 25th of Every Month

- 📅 2nd of the Following Month

After the final report is generated, a consolidated report is automatically sent to the Placement Coordinator.
